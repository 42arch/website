在 WebGL 和 3D 可视化开发中，交互是连接用户与虚拟场景的方式。点击屏幕时，如何判断鼠标下方到底是哪一个物体？

## 核心思路

GPU Picking 的核心思路是给每个物体分配一个唯一的颜色 ID，再把这些颜色绘制到不可见的离屏缓冲区（FBO）。用户点击时，读取对应像素的颜色，就能解码出物体的身份。

```ts twoslash
// 颜色 ID 映射原理
function idToColor(id: number): [number, number, number] {
  return [
    (id & 0x0000FF) / 255,
    ((id & 0x00FF00) >> 8) / 255,
    ((id & 0xFF0000) >> 16) / 255,
  ]
}

const pickedColor = idToColor(42)
//    ^?
```

## 性能与权衡

相较于逐个检查射线与几何体是否相交（Raycasting），这条路径把工作交给渲染管线。实际实现时，需要特别留意颜色管理、坐标换算以及读取像素带来的同步开销（`gl.readPixels` 会阻塞主线程）。
