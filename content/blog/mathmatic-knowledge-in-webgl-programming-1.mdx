直观理解，向量就是一个有大小和方向的箭头。大小表示箭头有多长，方向表示箭头指向哪里。二维向量可以写成 $(x, y)$，三维向量则多一个 $z$ 分量。

## 点与向量的区别

点表示空间中的位置，向量表示位移或方向。虽然它们都可以写成相同形式的坐标，参与运算时表达的含义却不同：

- **点 - 点 = 向量**（两点之间的位移向量）
- **点 + 向量 = 点**（沿向量平移后的新位置）
- **向量 + 向量 = 向量**（向量叠加）

## 单位向量与应用

例如向量 $(3, 4, 0)$ 的长度是 $5$。把各分量除以长度，就得到了保留方向、长度为 $1$ 的单位向量（Normalized Vector）：

```ts twoslash
function normalize(v: [number, number, number]): [number, number, number] {
  const length = Math.hypot(v[0], v[1], v[2])
  return length === 0 ? [0, 0, 0] : [v[0] / length, v[1] / length, v[2] / length]
}

const direction = normalize([3, 4, 0])
//    ^?
```

这是理解相机观察方向、表面法线（Normal）、光照计算与物体运动的基础。
