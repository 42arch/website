## 问题背景

macOS“储存空间”中“系统数据”占用过大。排查发现，`mediaanalysisd` 的 E5RT 模型缓存中堆积了大量未更新的临时 bundle 文件。

## 作用与影响

`mediaanalysisd` 为 macOS 媒体内容分析功能提供支持。停用后，“照片”中的人物、宠物、场景识别及相关精选集可能受影响。

## 清理过期临时包

以下命令删除缓存中超过一天未更新的 `.tmp.*.bundle` 目录：

```bash
CACHE="$HOME/Library/Containers/com.apple.mediaanalysisd/Data/Library/Caches/com.apple.mediaanalysisd/com.apple.e5rt.e5bundlecache"
find "$CACHE" -type d -name '*.tmp.*.bundle' -mtime +1 -prune -exec rm -rf {} +
```

## 停用或恢复服务

以下命令针对当前用户会话：

```bash
launchctl disable "gui/$(id -u)/com.apple.mediaanalysisd"
launchctl enable "gui/$(id -u)/com.apple.mediaanalysisd"
```

如果清理时遇到权限错误，可在“系统设置 → 隐私与安全性 → 完全磁盘访问权限”中允许终端访问。
