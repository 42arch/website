Design.fig

为什么之前显得「圆角太大、风格杂乱」？我们做了这 3 项核心修正：

当界面同时存在插画背景、多窗口、悬浮小组件与彩虹色图标，且全部使用 16px~24px 大圆角时，界面会显得像臃肿的玩具。收紧圆角曲率并收敛色彩后，立刻恢复了精密仪器般的工程秩序感。

RULE 01 / 几何收敛

严格的三级微圆角阶梯

  • • 窗口外框: 8px (原 16px)
  • • 内容卡片: 6px (原 16px)
  • • 按钮/标签: 4px~5px (原胶囊)
RULE 02 / 色彩降噪

告别彩虹色，单色+橙点缀

桌面与 Dock 图标统一收敛为深石墨灰（#374151），仅在悬停或核心强调处使用 PostHog 橙（#F54E00），消除花哨感。

RULE 03 / 空间留白

清理背景贴纸与冗余悬浮块

移除了插画天空中漂浮的文字徽章，默认收起左上角状态组件，让左侧窗口与右侧插画角色形成清晰的左右呼吸留白。

点击色卡可直接复制色值（85% 中性色 + 10% 石墨墨水色 + 5% 品牌橙）：
